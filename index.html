What the numbers mean


A GRUB tune is a list of whole numbers. The first number is the tempo. Everything after it comes in pairs: a pitch in hertz, then a duration.


480  440 1  880 2
│    │   │  │   └ duration: 2 units
│    │   │  └ pitch: 880 Hz (A5)
│    │   └ duration: 1 unit
│    └ pitch: 440 Hz (A4)
└ tempo


Tempo


Tempo sets the length of one duration unit: unit = 60 ÷ tempo seconds. Tempo 60 gives one second per unit, 120 gives half a second, 480 gives 0.125 seconds.


Pitch


Frequency in Hz. Use 0 for a rest. Values outside roughly 20 to 20000 Hz are silent, and a typical PC speaker sounds best between about 100 and 4000 Hz.


Duration


How many units the pitch lasts. Seconds = duration × 60 ÷ tempo. So 480 440 1 is one 440 Hz beep lasting 0.125 seconds.

Add a tune to GRUB


1. Set the tune


Edit /etc/default/grub as root and add or change this line. Keep the quotes.


GRUB_INIT_TUNE="480 440 1"


2. Regenerate the config


# Debian, Ubuntu, Mint
sudo update-grub

# Fedora, RHEL, openSUSE (BIOS or UEFI)
sudo grub2-mkconfig -o /boot/grub2/grub.cfg

# Arch, Gentoo, most others
sudo grub-mkconfig -o /boot/grub/grub.cfg


The generated grub.cfg now contains a play line that runs each time GRUB starts, before the menu appears.


3. Try it without rebooting into a full test


At the GRUB menu press c for the command line and type play 480 440 1. Press Esc to go back. This is the quickest way to check what your hardware does.


Tune on one menu entry only


Put play inside a custom entry in /etc/grub.d/40_custom, then regenerate the config:


menuentry "Windows" {
    play 480 880 1 440 1
    chainloader +1
}


Troubleshooting


GRUB uses the PC speaker, not your sound card. Many laptops, newer desktops and virtual machines have none or leave it muted. Check that the speaker or buzzer is connected, the volume in firmware setup allows it, and in QEMU that a PC speaker device is enabled. The browser preview here is a square wave to imitate that sound, so real hardware will differ.
